# 深沟球轴承设计任务数据集 · V2（80 条，五型号集中版）

## 定位

80 条**合成**单列深沟球轴承设计任务，配套 80 段包含全部用户输入的一次性自然语言描述，用于 Conversation Agent 的**单轮需求理解、参数提取、约束识别**测试；不含固定 Agent 对话剧本。

**本版主要变更：** 从原先分散的 41 个型号收敛到 **6205、6204、6206、6005、6305** 共五个原版 RoBAS 真实型号，其中以 **6205 为主（30 条）**。原有案例 ID `DGB-0001`～`DGB-0080` 和五类优化目标、1/2/3 项性能约束数量、10 种语言风格保留。为避免把原来大尺寸型号的高负载场景直接移到小尺寸轴承，一部分合成工况的**转速、Fr、Fa 数值也已重新设定**，不应视为与上版同编号案例的完全相同输入。变化是样例设计时使用的简单尺寸比例启发式，**不代表真实载荷能力计算、额定转速检验或工程可行性证明**。

## 文件

- `data/design_cases.jsonl`：每行一条完整结构化需求，业务字段、五变量锁定/范围、原版 RoBAS 物性及源 SHA-256、待审核状态。
- `data/user_requests.jsonl`：每行一段完整自然语言需求；`case_id` 对应唯一设计任务；不包含参考 Agent 回答。
- `review/case_review.csv`：可在 GitHub 或表格工具里快速查看的 80 条索引。
- `schema/DGBCase_v2.schema.json`：结构校验；**格式未因本次集中型号而增加无关包装**。
- `scripts/generate_dgb_cases_v2.py`：从授权提供的 RoBAS ZIP 读取原始型号、材料与润滑物性，确定性生成本数据集。
- `scripts/validate_dgb_dataset.py`：格式、两文件配对、文本/数值核对和真实源资源核验；本版可加 `--focused-80` 检查型号配额和覆盖。

### 目标、约束、优化模式

- 五类主要优化目标：功耗最小 26 条、寿命最大 21 条、温升最小 11 条、接触压力最小 12 条、刚度最大 10 条。**每个型号都覆盖全部五类优化目标。**
- 性能硬约束项数：单约束 42 条、双约束 32 条、三约束 6 条；约束值是用户的合成需求，不是实际满足情况。
- 五变量模式：完全自由 23 条、只有锁定 8 条、只有边界 45 条、同时锁定和边界 4 条。五个内部参数为 Dw、Z、Dpw、fi、fo。

## RoBAS 数据来源与真实性边界

- 源文件：用户提供的 `RoBAS_Resources.zip`，SHA-256 `d5b072f08f3a76e283d35215e91097d88a1702e6ff5f3c6675cc726d3e73b626`，不在本数据集中再分发完整原库。
- 型号库：`RoBAS_Resources/Data/DGBData.db`，SHA-256 `4b0e9c56a4d216cf952ce13e31676c4e509130530b872d724a2dfe4c6186878f`；五个型号 d/D/B 全部精确匹配。
- 材料库：`RoBAS_Resources/Resource/materialDB.csv`，SHA-256 `9e018aeced3bbe924b02c59f0761468e3558107ebdc110d943b247024e768bc1`；仅使用 `氮共渗轴承钢`、`渗碳轴承钢` 和保持架用 `工具钢` 的原始行与六项物性。
- 油品库：`RoBAS_Resources/Resource/lubricantDB.csv`，SHA-256 `4b0372b04e1d8a0b25cb8c811b9a3c3aaacbb5fae6f3f38e8b01742879606434`；使用 `VG22`、`VG32`、`VG46`、`VG68`、`VG100` 的原始黏温点及物性。
- `6204`、`6205`、`6206` 在本版 RoBAS `主参数` 表中有可匹配的参考钢球几何；**`6005`、`6305` 在该表没有对应记录**，因此后两者没有使用需要原始参考钢球直径、钢球数或节圆直径的锁定/区间模式。**缺少参考内部几何不表示缺少型号本身或外形尺寸。**
- 所有保持架选项 `StampingCage` 沿用原版 C# 的类存在性证据，不表示选定材料与高速工况已审通过。
- 初始游隙组 CN/C3、轴配合 k5/m5、座孔 H7 均为合成用户选择，**尚未完成具体配合、工作游隙与润滑适用性审核**。
- 采用的是**真实目录值 + 人工合成设计场景**；不得将 `catalog_verified=true` 混淆为工程可行性验证。所有 80 条 `engineering_reviewed=false`、`solver_verified=false`。性能指标没有实际计算标签，不能直接用于数值优化性能训练。
- 选择五型号是为了减少不必要的尺寸变量混杂，便于先做 6205 单型号需求评估，再比较 6204/6206 的内径变化和 6005/6305 的尺寸系列变化。**这些案例并未证明每个工况对该型号可行。**

## 运行校验及复现

在项目目录中安装 Python 3.11+ 与 `jsonschema`：

```bash
python scripts/validate_dgb_dataset.py --focused-80
python scripts/validate_dgb_dataset.py --focused-80 --robas-archive /path/to/RoBAS_Resources.zip
python scripts/generate_dgb_cases_v2.py --robas-archive /path/to/RoBAS_Resources.zip
```

第一个命令核对结构、80 条配对、每型号配额、10 风格配额、五目标覆盖；第二个在持有相同原版 ZIP 的条件下严格复核 SQLite/CSV 原始记录、来源哈希与所选物性；第三个确定性重新生成 80 条设计任务、自然语言及审核表。

**适用范围：** 第一阶段需求 Agent 的单轮完整需求识别与结构化评估。若研究动态追问，需要另行设计不完整输入场景；若研究五参数优化，需要补齐适用性审核、物理/几何校核与真实 RoBAS 求解结果。
