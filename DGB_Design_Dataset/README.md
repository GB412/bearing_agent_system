# 深沟球轴承设计任务数据集 · V2（80 条，单轮完整需求）

## 目标与使用方式

这是**80 条结构化深沟球轴承设计任务**与其一一对应的**80 段单次完整自然语言需求**。结构化任务提供隐藏的目标值，自然语言是给被测 Conversation Agent 的输入；Agent 的 `DesignBrief` 根据同一用户层业务字段比较，不需要复制数据库快照。此版本**不包含固定多轮对话脚本**，因此主要评估单轮完整需求理解、提取、约束识别和数据一致性，不能据此宣称动态追问能力已验证。

本次沿用 24 条既有设计任务（其结构化 JSON 业务数据完全不变），新增 **56 条**不同型号、稳态工况、硬约束和优化变量限制的合成需求。为提高自然语言多样性，**80 条文本全部重新表述**为十种语言风格，每种 8 条：工程技术交底 8 条；日常口语 8 条；项目委托 8 条；参数清单 8 条；目标先行 8 条；简明压缩 8 条；约束先行 8 条；现场说明 8 条；设计复核 8 条；工况先行 8 条。不同风格主要体现信息顺序、叙述口吻、结构化程度，而**每段都包含该案例全部用户层设计输入**。

## 文件组织

- `data/design_cases.jsonl` — 80 条业务结构化任务，保留具体型号尺寸、工作条件、工程配置、性能目标、五变量优化要求、RoBAS 实际物性快照与来源哈希。
- `data/user_requests.jsonl` — 80 段单轮完整需求，字段 `case_id` 一一关联；`language_style` 记录本条语言风格；不存任何 Agent 参考回复。
- `schema/DGBCase_v2.schema.json` — 结构类型及基础范围验证。
- `review/case_review.csv` — 80 条简要审阅索引，含 `language_style`、工况、目标、质量状态。
- `scripts/generate_dgb_cases_v2.py` — 从用户提供的 RoBAS ZIP 读取原版目录，按固定案例规格生成全部数据。
- `scripts/validate_dgb_dataset.py` — 结构/跨文件/语言数值核对；提供原始 ZIP 时重新核对目录实际行和源 SHA-256。

## 来源及适用性边界

**原始 RoBAS 资源版本**：由用户提供 `RoBAS_Resources.zip`，归档 SHA-256 `d5b072f08f3a76e283d35215e91097d88a1702e6ff5f3c6675cc726d3e73b626`。

- `RoBAS_Resources/Data/DGBData.db`（SHA-256 `4b0e9c56a4d216cf952ce13e31676c4e509130530b872d724a2dfe4c6186878f`）中存在所有选定型号，尺寸以该库 `model` 表查询为准；锁定的球数 Z 从同库 `主参数` 表查询。**型号外形真实不等于以该型号内部几何作为最终最优结构。**
- `RoBAS_Resources/Resource/materialDB.csv`（SHA-256 `9e018aeced3bbe924b02c59f0761468e3558107ebdc110d943b247024e768bc1`）中可精确找到使用的 `工具钢、氮共渗轴承钢、渗碳轴承钢`，并将原库六项物性与行号复制到各案例中。数据异常不自行修正。
- `RoBAS_Resources/Resource/lubricantDB.csv`（SHA-256 `4b0372b04e1d8a0b25cb8c811b9a3c3aaacbb5fae6f3f38e8b01742879606434`）中可精确找到 `VG100、VG22、VG32、VG46、VG68`，并保存各自原始黏温点和其他数值。
- 保持架类型沿用原版 DGB C# 源码中已找到的 `StampingCage` 类；游隙组 CN/C3 及 k5/m5/H7 配合为**合成用户的候选选择**，**没有证据将其标记为已通过 RoBAS 配合/游隙审核**。材料和油的数据库存在也不等于组合在某工况下合格。
- 所有转速、载荷、温度、性能目标、约束范围、部分优化边界为人工生成的设计**输入要求**，不是厂家额定值、工程可行性证明、材料性能预测或求解结果。对高速/高载组合尤其需要先筛查，存在潜在不适用或不可行案例。
- 所有 `quality` 中均有 `scenario_origin=synthetic`、`catalog_verified=true`（仅源目录匹配）、`engineering_reviewed=false`、`solver_verified=false`。**不能直接用于真实 RoBAS DATA 输入或五变量优化算法的真实数值性能标签。**
- 部分约束涉及 `L10h`、摩擦功耗、温升、峰值接触压力和径向刚度，当前数据**未验证 RoBAS 具体适配器能否计算所有这些指标**，也没有假装这些约束被满足。
- 语言风格为有限模板驱动的合成表达：覆盖十种常见表达形式，但不相当于 80 个独立真实用户语料。后续进行论文正式泛化试验，建议对一部分文本进行人工改写及盲评，不要把模板多样性等同真实语言分布。

## 校验与重现

需要 Python 3.11+ 和 `jsonschema`。

```bash
python scripts/validate_dgb_dataset.py
python scripts/validate_dgb_dataset.py --robas-archive /path/to/RoBAS_Resources.zip
# 重新生成（会覆盖 design / requests / review）
python scripts/generate_dgb_cases_v2.py --robas-archive /path/to/RoBAS_Resources.zip
```

校验包括：Schema、案例/自然语言一一对应、型号与尺寸一致、优化锁定和边界、自然语言关键值、十种风格枚举、档案哈希及原 RoBAS SQLite/CSV 的实际记录匹配。**仅运行离线验证，不会替代 `--robas-archive` 的真实库核验。**

数据批次均为合成样例，提交到仓库便于需求 Agent 研究开发和审阅；实际进入第二阶段数值优化前，须另行建立工程审查与真实 RoBAS 计算证据。
