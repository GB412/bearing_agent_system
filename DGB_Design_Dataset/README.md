# 深沟球轴承设计任务数据集 · V2 修订质量版（5 型号 / 80 条）

> **状态：合成需求评测数据，未通过工程审核，也没有真实 RoBAS 求解结果。** 修复的是输入质量和测试工具，不等于证明设计可行。2026-11-23。

## 用途和文件

每个 `case_id` 对应 `data/design_cases.jsonl` 中的一条结构化参考需求，以及 `data/user_requests.jsonl` 中的一段**完整单轮自然语言需求**。可用于需求 Agent 的参数抽取、约束辨识、锁定/优化变量识别评测；不包含固定 Agent 多轮回复，不可作为优化器监督训练所需的“性能真值”。

`review/case_review.csv` 是含初筛记录的核查索引；`schema/DGBCase_v2.schema.json` 是结构约束；`scripts/generate_dgb_cases_v2.py` 可从用户持有的真实 RoBAS ZIP 确定性重建；`scripts/validate_dgb_dataset.py` 验证跨文件、生成文案、字段及数据来源；`tests/test_dgb_dataset_v2.py` 是反向错误注入测试。

## 这次修复了什么

1. **自然语言 Z 锁定矛盾**：不再把已锁定的 Z 同时列为待优化变量；锁定、边界与自由优化都由同一结构化记录生成。
2. **硬约束语义**：寿命下限、摩擦功耗/温升/接触压力上限均明确写成“必须 / 不超过 / 不低于”，与 JSON 操作符对应，软偏好和硬约束不混写。
3. **输入异常筛查**：使用 `RoBAS_Resources/Data/bearing.db` 中 `T_SKFA01` 的 C、C0、nmax 参考值重新筛选原有合成载荷/转速。仅作**异常输入排除**，绝不等价于工程可行性。与旧版比较，59 条案例的速度或载荷数值经过重设，原严重工况被新工况**替代而非静默标记通过**；调整前后数值均可在审核 CSV 中对照。所有原案例 ID 保留，但更改值的 ID **不再指代旧版同一个任务**。
4. **温升参考**：21 条有温升目标/约束的案例补充了合成 `ambient_temperature_c`；`temperature_c` 明确是**初步假定分析温度而不是模型预测值**。**尚未有热平衡/边界散热模型，不能声称温升约束可计算。**
5. **校验漏洞**：采用严格生成文案复现，拒绝 `Fr=300` 被改为 `Fr=3000`、`rpm` 单位或寿命不等号被篡改，以及锁定参数仍被列为自由优化。审核 CSV 逐字段校核而非只检查 ID。
6. **几何必要性初筛**：对于存在原库 `主参数` 参考几何的 6204/6205/6206，检查受限制 Dw/Dpw 在参考邻域是否明显越过 d/D 外形、固定 Z 是否发生基本钢球周向重叠。**不是完整几何装配或可行域证明。** 6005/6305 缺参考内部几何，不能自动判定其候选五变量空间可行。

初筛对含寿命约束的任务仅用 **Fr 作为等效动载荷 P 的粗略替代**，结合目标寿命 `L10h` 估算 `C_proxy=Fr*(60*n*L10h/1e6)^(1/3)`。对所有案例同时参考 `Fr/C0`、`n/nmax`。这只是一项筛选掉明显夸大输入的启发式，未计算真实 P、修正寿命、热平衡、接触应力、润滑状态、游隙或几何完整可行域，不能作为工程可行标签。为避免筛选值全部堆叠在单一阈值，合成样例采用稳定散列确定不同筛查参考比值，其取值也**不是工程规定的安全系数**。

筛查调整后，寿命代理比值范围为 0.084–0.739，最大 `n/nmax`=0.878。调整前参考输入可在 `review/case_review.csv` 的 `original_*` 列中找到，异常较大的原始任务内容不会再作为正式自然语言评测输入。

## 当前仍然存在的边界

- **全部 80 条：** `engineering_reviewed=false`, `solver_verified=false`，且 `reference_screen.status=REFERENCE_ONLY_NOT_ENGINEERING_APPROVED`。未验证定制内部参数的额定动载荷、温升、接触应力、刚度或功耗。
- **材料、润滑剂、配合与游隙**均为用户假定选择：CSV 存在该记录只证明目录名称及物性来源一致，不能证明这些组合是合格配置。样例仍存在材料与油品/配合的统计关联，不能作为工程搭配规则学习材料。
- **五变量可行域：** Dw、Z、Dpw、fi、fo 的 `bounds` 是用户提出的限制条件，而非由求解器认证的全域。6005、6305 缺参考内部参数，暂不自动构造依赖参考球径或球数的限制。
- **性能约束**只代表用户希望满足的目标。`temperature_rise_c` 即使有环境温度也缺热模型；摩擦功耗、刚度和压力的实际数值能力依赖真实 RoBAS 计算路径。
- **语言风格**为 10 组确定性模板，全部完整单轮输入。没有独立的真实用户语言分布，也无法仅凭本数据集评估多轮动态追问能力。

## 复现与校验

在项目根目录安装 `jsonschema`，并准备持有的原始 RoBAS 资源包：

```bash
python scripts/generate_dgb_cases_v2.py --robas-archive /path/to/RoBAS_Resources.zip
python scripts/validate_dgb_dataset.py --focused-80 --robas-archive /path/to/RoBAS_Resources.zip
python -m unittest discover -s tests -p 'test_dgb_dataset_v2.py' -v
```

**特别说明：** 此次调整通过更改确定性生成逻辑产生新版本，不能与此前同 ID 的旧数据混用；后续评测应按 Git commit 固定快照，保存数据版本、模型设置和完整输出。验证通过的是文本/数据一致性与目录一致性，不能替代专业工程复核或真实数值求解。
